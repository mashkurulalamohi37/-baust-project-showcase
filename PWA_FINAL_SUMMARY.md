## 🐛 Troubleshooting

### Common Issues & Solutions

**Issue:** Install banner doesn't appear on iOS
```
Solution:
- Use Safari browser (not Chrome)
- Wait 3 seconds after page load
- Clear cache: Settings → Safari → Clear History
- Check if already installed
```

**Issue:** App doesn't work offline
```
Solution:
- Check service worker in DevTools
- Clear cache and reinstall
- Rebuild: flutter build web --release
- Redeploy: firebase deploy --only hosting
```

**Issue:** Firebase deployment fails
```
Solution:
firebase logout
firebase login
firebase deploy --only hosting
```

**Issue:** Icons don't show correctly
```
Solution:
- Verify icons exist in web/icons/
- Clear browser cache
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
```
