🌐 Access the app: https://projectshowcase-56c2b.web.app

📱 How to Install on iPhone/iPad:
1. Open the link above in Safari (must use Safari)
2. Wait a few seconds - you'll see an install guide
3. Tap the Share button (📤) at the bottom
4. Select "Add to Home Screen"
5. Tap "Add"
6. Done! The app icon will appear on your home screen

🤖 How to Install on Android:
1. Open the link above in Chrome
2. Tap the install prompt that appears
3. Or tap Menu → "Add to Home Screen"

💻 Desktop Users:
Just visit the link in any browser - no installation needed!
